# NestJS + MongoDB Atlas API

Proyecto backend desarrollado en NestJS con integración completa a MongoDB Atlas para la gestión de proyectos.

##  Características
- Arquitectura limpia en módulos (Controllers, Services, DTOs y Schemas).
- Conexión remota y segura a base de datos en la nube (MongoDB Atlas).
- **Fix de DNS para Windows:** Implementa solución nativa para corregir la regresión de Node.js en la resolución de cadenas `mongodb+srv` mediante servidores de respaldo (Cloudflare/Google).
